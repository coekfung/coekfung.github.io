# Website Structure

An English, single-page personal website built with [Tufted](https://tufted.vsheg.com/). No CV for now.

Organize the page in this order:

1. **Personal Introduction** — A brief introduction at the top.
2. **First-Author Publications** — Each entry contains a citation in ACM reference format, followed by a short description, with a representative image in the side margin.
3. **Other Publications** — All remaining publications at the end, using the same citation format, without descriptions or images.

# Git Commit Messages

Use [Conventional Commits](https://www.conventionalcommits.org/): `<type>[optional scope]: <description>`, e.g. `feat(publications): add a new paper` or `fix(layout): align margin notes`.
